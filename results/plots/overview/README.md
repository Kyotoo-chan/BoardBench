# BoardBench overview figures

Shared thesis figures live here. They mix each game's current presentation card rather than one global rubric version.

Generated by `generation/plot_thesis_overview.py`.

- `evidence_profiles.png`: all current games and retained conditions with one shared legend.
- `intervention_deltas.png`: each retained intervention minus that game's original run, in three separate panels.

Clear-basis scenarios, human-decision-basis scenarios, and neutral judge means remain separate; judge error bars show sample SD (`n=3`). Deltas are observed changes from single adapted runs, not causal estimates or independent replications.

The overview uses Abalone's v3 replay, which does not score the unspecified no-move pass; the v2 Abalone profile remains in `../abalone/v2/`. Other games keep their v2 cards. Bohnanza includes the retained emphasis repeat and structured clarification. `6 nimmt!` has no intervention condition.

Not plotted:

- technical gates, rollout robustness, scenario evaluated coverage, and player-count probes, because the current runs are uniformly complete/passing and a chart would add little information;
- token use, runtime, cost, and code size, because they are implementation-efficiency evidence rather than answers to the rule-fidelity questions;
- persona reviews, because they are optional supplementary evidence and not comparable across every condition.
