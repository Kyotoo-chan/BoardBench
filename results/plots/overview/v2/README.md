# BoardBench V2 overview figures

Generated by `generation/plot_thesis_overview.py` from the committed schema-v2 result cards.

- `evidence_profiles.png`: all current V2 games and retained conditions. Clear-basis scenarios, human-decision-basis scenarios, and neutral judge means remain separate; judge error bars show sample SD (`n=3`).
- `intervention_deltas.png`: each retained intervention minus its game's original V2 run, again in three separate panels. These are observed changes from single adapted runs, not causal estimates or independent replications.

The curated mapping intentionally uses CATAN's evaluator-r3/Judge-packet-r2 cards and includes Bohnanza's retained emphasis repeat and structured clarification. `6 nimmt!` has no intervention condition.

Not plotted:

- technical gates, rollout robustness, scenario evaluated coverage, and player-count probes, because the current runs are uniformly complete/passing and a chart would add little information;
- token use, runtime, cost, and code size, because they are implementation-efficiency evidence rather than answers to the rule-fidelity questions;
- persona reviews, because they are optional supplementary evidence and not comparable across every condition.
