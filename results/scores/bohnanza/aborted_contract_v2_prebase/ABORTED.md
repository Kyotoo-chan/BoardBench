# Aborted contract-v2 pre-base-rulebook run

Status: **aborted before judging and comparison**.

Four generations completed on 2026-07-19 using the earlier augmented Bohnanza source conditions. The study was stopped when a newly supplied complete base-game rulebook replaced that source condition.

The run also exposed an evaluator-contract gap: all implementations passed the reachable-state contract gate, but the scenario replay produced 9–15 `UNTESTABLE` cases per run because `state_from_data` rejected complete rare-state fixtures. These artifacts are therefore diagnostic only and must not be combined with the original source experiment or the new base-game run.

Raw generations, event logs, usage, checks, scenario outputs, and the exact frozen method files are retained for provenance. No Judges were run.
